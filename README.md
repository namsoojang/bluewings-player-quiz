# 누구게, 블루윙즈! — 수원삼성 선수 맞히기

수원삼성 공식 선수단에 등록된 40명의 사진으로 진행하는 한국어 객관식 게임입니다. 스마트폰 한 화면을 함께 보고 이름을 골라 주세요. 사진과 선수 정보는 모두 로컬 파일이며 실행 중 외부 API를 호출하지 않습니다.

## 바로 플레이

[게임 시작](https://namsoojang.github.io/bluewings-player-quiz/) · [GitHub 저장소](https://github.com/namsoojang/bluewings-player-quiz)

스마트폰과 PC에서 링크로 바로 접속합니다. 회원가입은 필요하지 않으며 플레이 결과는 각 브라우저에만 저장됩니다.

## 실행

Node.js 20.19 이상 또는 22.12 이상 환경에서:

```sh
npm install
npm run dev
```

PC에서는 http://localhost:5173 을 엽니다. 터미널에 다른 포트가 표시되면 해당 포트를 사용합니다. 개발 서버가 실행되는 동안 접속할 수 있습니다.

같은 Wi-Fi의 스마트폰에서 접속하려면:

```sh
npm run dev -- --host 0.0.0.0
```

Windows PowerShell에서 `ipconfig`로 PC의 Wi-Fi IPv4 주소를 확인하고 스마트폰에서 `http://PC주소:5173`을 입력합니다. 예: `http://192.168.0.12:5173`. Windows 방화벽의 개인 네트워크에서 Node.js 접근을 허용하세요. PC와 서버가 켜져 있어야 합니다. 스마트폰에서 `localhost`는 PC를 가리키지 않습니다.

## 게임 규칙

- 10명 / 20명 / 전체 40명 중 출제 수를 선택합니다. 출제 순서와 네 개의 보기를 무작위로 구성하며 선수는 한 게임에 한 번만 출제합니다.
- 첫 화면은 얼굴을 가로 8칸 × 세로 8칸으로 나눈 64칸 중 얼굴 내부의 작은 한 칸만 무작위로 공개하며, 정답 배점은 100점입니다.
- 추가 힌트는 아직 열리지 않은 사진 한 칸 또는 아직 공개하지 않은 나이·키·포지션 중 하나를 무작위로 공개합니다.
- 사진 힌트는 아직 열리지 않은 한 칸을 무작위로 추가 공개합니다. 기존 공개 칸은 유지되며 공개 순서는 문제별로 저장해 새로고침해도 바뀌지 않습니다. 정답 선택이나 시간 종료 후에는 전체 사진을 보여 줍니다.
- 힌트마다 배점이 15점 감소합니다. 100 → 85 → 70 → 55 → 40 → 25 → 10 → 10점입니다. 사진 63회와 정보 3회로 최대 66개의 추가 힌트가 있습니다. 최저 배점 10점에 도달한 뒤에는 추가 힌트를 사용해도 10점을 유지합니다.
- 정답이면 현재 배점을 받고 전체 사진을 공개합니다. 오답이면 문제를 종료하지 않고 배점을 15점 낮춘 뒤 선택한 선수를 보기에서 제외하고 새 후보로 교체합니다. 이전에 틀린 후보는 같은 문제에 다시 등장하지 않으며 30초 타이머는 그대로 흐릅니다. 새 후보가 모두 소진되면 오답 보기만 제외합니다. 최저 배점은 10점이며 시간 종료만 0점입니다. 중복 점수 처리는 차단합니다.
- 선수 한 명당 제한시간은 30초로 고정입니다. 시간 종료는 0점이며 정답과 전체 사진을 공개합니다. 일시정지·재개, 음향 ON/OFF를 지원합니다.
- 전체 누적 시간은 첫 문제 시작부터 마지막 답 확정(또는 마지막 시간 종료)까지 측정합니다. 일시정지·문제 사이 대기·시작 화면 이동·새로고침 중에도 실제 경과 시간을 포함합니다. 결과 버튼을 누르기까지의 대기는 포함하지 않습니다.
- 참가자·팀 이름과 총점·완료 시간을 완주 기록으로 저장합니다. 같은 문제 수에서 점수 내림차순, 동점이면 완료 시간 오름차순으로 상위 10개 기록을 보여 줍니다. 조기 종료는 완주 기록에서 제외하며, 기록은 해당 브라우저에만 저장됩니다.
- 시작 화면으로 돌아가면 개별 문제 타이머를 정지합니다. 새로고침 시 문제 순서·보기·공개 힌트·점수·타이머가 복구됩니다. 실행 중 타이머는 실제 종료 시각을 기준으로 계산합니다.
- 결과에는 총점·정답·오답/시간 종료·정답률·미응답 수와 문제별 점수를 표시합니다. 조기 종료의 정답률은 전체 출제 문제 수 기준입니다.
- 사진 로딩 실패 시 안내 화면을 보여 주며 정보 힌트와 보기로 계속 진행할 수 있습니다.

## 선수 사진 정리

[공식 선수단 페이지](https://www.bluewings.kr/player/pro)의 **2026-10-09 수집 자료**입니다. 등록된 전체 40명(GK 4 / DF 14 / MF 10 / FW 12)의 공개 사진을 내려받았습니다. 이후 이적·프로필 변경은 자동 반영하지 않습니다.

- `public/images/players/`: 공식 원본 사진 40장, 선수 ID로 파일명 관리
- `src/players.json`: 이름·생년월일·키·몸무게·포지션·등번호·사진 원본 주소·얼굴 및 눈 좌표
- `players-source.json`: 공식 선수 페이지가 제공한 원본 데이터 스냅샷
- `docs/선수사진목록.md`: 이름별 정리 표와 로컬 사진 링크
- 게임의 **선수 도감**: 전체 사진·프로필, 이름 검색, 포지션 필터, JSON 명단 내보내기

나이는 생년월일로 계산한 만 나이입니다. 게임 중 나이는 게임 시작일 기준, 도감은 현재 로컬 날짜 기준입니다. 얼굴 좌표는 원본을 변경하지 않고 분석했으며 게임에서 CSS 마스크로 부분 공개합니다. 그림이나 사진에 이름을 덧붙이지 않습니다.

배경은 수원삼성 로고와 파랑·하양·빨강 세로 줄무늬입니다. 로고와 선수 사진은 구단 공식 자산입니다. 사진의 권리는 해당 권리자에게 있습니다.

## 기술 및 검증

React + TypeScript + Vite, Tailwind CSS, Lucide React. 로그인·백엔드·외부 데이터베이스 없음. GitHub Pages로 정적 배포합니다. 게임 설정과 진행은 별도 localStorage 키에 저장하며 기존 속담 진행 데이터와 충돌하지 않습니다.

```sh
npm test
npm run build
npm run preview
```

선수 게임 자동 테스트는 `src/player-game.test.ts`에 있습니다. 선택적인 브라우저 검증은 개발 서버를 켠 뒤 Python/Playwright 환경에서 `python scripts/player-browser-test.py`로 실행합니다. 얼굴 자료 생성 도구 `scripts/prepare-players.py`는 개발용이며 게임 설치·실행에 Python/OpenCV가 필요하지 않습니다.

로컬 작업 폴더의 `archive/proverb-game/`에 기존 속담 게임을 보존했습니다. 보관용 폴더와 테스트 캡처·개발 도구는 공개 저장소에 포함하지 않습니다.
## GitHub Pages 업데이트

main 브랜치에 코드를 올리면 .github/workflows/pages.yml이 자동으로 설치·테스트·빌드한 뒤 GitHub Pages에 반영합니다. 저장소 Settings → Pages의 Source는 GitHub Actions입니다. 로컬 실행 방법도 그대로 사용할 수 있습니다.

## 결과 이미지 저장과 공유

결과 화면의 팬심 성적표에는 종합 점수, 소요시간, 전체 선수단 40명 얼굴 모자이크, 선수별 점수 색상, 맞힌 선수 및 오답 시도/놓친 선수 명단이 들어갑니다. 재도전해서 맞힌 선수는 두 명단에 표시해 과정도 남깁니다.

이미지 저장 버튼으로 성적표만 한 장의 PNG로 다운로드할 수 있습니다. 공유하기는 파일 공유가 가능한 브라우저에서 기기의 공유 메뉴를 열고, 지원하지 않으면 이미지 저장으로 안내합니다. 앱에 실제로 보내는 것은 사용자가 선택합니다. 공유 이미지에는 참가자/팀 이름이 들어갑니다.

사진과 캔버스는 같은 정적 사이트에서 읽으며, 이미지 생성·저장에도 외부 서비스나 서버가 필요하지 않습니다. 이전 규칙의 진행은 v3 키에 보존하고 새 재도전 규칙은 v4 키에 따로 저장합니다.

### 콤보와 선수 배지
- 첫 선택에 정답을 맞히면 연속 콤보가 쌓이며, 2콤보부터 잠깐 이벤트 팝업이 나타납니다. 힌트를 사용해도 첫 선택 정답이면 콤보에 포함됩니다.
- 오답 선택 또는 시간 종료 시 콤보가 끊깁니다. 콤보는 추가 점수 없이 도전 기록으로 표시됩니다.
- 추가 힌트 없이 맞힌 선수는 노힌트 배지를 받습니다. 오답 후 재도전 정답도 포함하며 재도전 표시를 붙입니다.
- 결과 화면과 공유 이미지에 최대 콤보, 배지 개수, 노힌트 선수 명단이 함께 표시됩니다. 새로고침 시 기록은 복구되지만 팝업은 다시 재생되지 않습니다.
